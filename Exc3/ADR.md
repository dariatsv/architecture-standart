### <a name="_qmphm5d6rvi3"></a>**Решение**

Для начальной версии решения будут использованы текущие технологии и инструменты с минимальными изменениями, что обусловлено имеющимися ограничениями. В систему будет добавлен сервис для сбора метрик из АБС с использованием JMS для асинхронной передачи данных (модель точка-точка), так как потребитель данных один и модель "потребитель-издатель" вызывает необходимость синхронизации работы потребителей в процессе отправки.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

Существует возможность перехода на микросервисную архитектуру с асинхронным взаимодействием между компонентами, а также частичная или полная замена стека технологий.

**Недостатки, ограничения, риски**

* АБС ограничена только вертикальной масштабируемостью.
* Необходимость соблюдения стандартов хранения персональных данных.
* Рекомендуется избегать прямого взаимодействия с API АБС.
* Использование MS SQL и Oracle в качестве основных технологий ограничивает возможности.
